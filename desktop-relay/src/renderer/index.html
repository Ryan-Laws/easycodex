First time?

Run Install/build once before starting the relay.

  1. 第一次使用先点“安装/构建”，完成依赖准备。
  2. 点“启动中继”，等右上角状态变成在线或等待手机连接。
  3. 用手机相机扫右侧二维码导入地址和 API Key，然后在手机里创建任务。
